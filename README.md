# Anniversary Guest Dashboard

A single-file, offline-friendly guest planning dashboard for the First Death Anniversary remembrance event.

## Features

- Guest list with categories, party size, arrival location, attendance probability and confirmation status
- Overview metrics, category/venue/party-size charts and recent activity
- Search, filter, sort, bulk confirm and bulk mark-attended
- Add, edit and remove guests (saved in the browser's `localStorage`)
- Food menu management with editable dish groups
- CSV export of the full guest list
- Dark and light themes, responsive layout for mobile

## Run locally

Open `index.html` in any modern browser. No build step or server is required.

## Notes

- All edits are stored in the browser's `localStorage`; use **Export CSV** to keep a backup.
- The initial guest list is embedded in the page, so this repository is public. Do not commit private contact details you do not want published.
